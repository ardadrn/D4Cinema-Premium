### 🚀 Technical Architecture & Features
Engineered with a focus on performance, scalability, and an exceptional user experience, breaking the boundaries of standard WinForms applications:

* **x64 Native Architecture:** Fully optimized for 64-bit processing to ensure robust memory management, particularly when rendering high-resolution media assets and handling heavy database transactions.
* **High-Fidelity UI (60 FPS):** Implemented hardware-accelerated rendering utilizing `WS_EX_COMPOSITED` and `DoubleBuffered` techniques to completely eliminate UI flickering, delivering a seamless and fluid user experience.
* **Embedded SQLite Engine:** Utilizes a zero-configuration, highly portable SQLite database architecture for rapid and reliable data persistence without requiring external server setups.
* **Real-Time Analytics Dashboard:** Features a dynamic management panel executing optimized SQL Scalar queries to instantly reflect active screenings, user metrics, and live ticket sales.
* **Asynchronous Splash Engine:** Custom-drawn, anti-aliased boot sequence with smooth fade-in/out transitions, providing a premium application launch experience.
